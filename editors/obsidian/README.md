# Zacess for Obsidian

An Obsidian theme with Zacess Light for light mode and Zacess Dark for dark mode, plus the Yellow on
Black, Cream, High Contrast Dark, High Contrast Light, Deep Contrast Dark and Deep Contrast Light
themes through the Style Settings plugin. Body text, muted text, links and code
colours all keep at least 7:1 contrast on the page. Obsidian keeps each character's colour inside a
selection, so the selection is a fill in the theme's own hue with body text at 7:1 and code
colours, muted text and links at 4.5:1 or more over it. Links are underlined and every control shows
a focus ring.

## Install

1. Download `zacess-obsidian-<version>.zip` from the
   [latest release](https://github.com/zacesshq/themes/releases/latest). The same `manifest.json` and
   `theme.css` are in this folder.
2. Put both files in a folder named `Zacess` inside your vault's `.obsidian/themes/` folder.
3. Open **Settings**, then **Appearance** and choose **Zacess** under **Themes**.

Obsidian's own **Base color scheme** setting switches between Zacess Light and Zacess Dark.

## Yellow on Black, Cream and the high contrast themes

Install the community plugin [Style Settings](https://github.com/mgmeyers/obsidian-style-settings),
open its settings and choose **Contrast theme** under **Zacess**. Yellow on Black, Cream, High
Contrast Dark, High Contrast Light, Deep Contrast Dark and Deep Contrast Light replace both the light and the dark mode while they are
chosen.

> [!NOTE]
> Zacess is in the [Obsidian community directory](https://community.obsidian.md/themes/zacess), so it can also be installed from
> **Settings**, **Appearance**, **Manage** by searching for **Zacess**. The directory installs from
> [zacesshq/obsidian-theme](https://github.com/zacesshq/obsidian-theme), a read-only copy of this
> folder that each release updates.
