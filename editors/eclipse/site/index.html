Zacess Themes for Eclipse

This address is an Eclipse update site. Eclipse reads it directly, so there is nothing to download here in a browser.

Install

  1. In Eclipse, open Help, then Install New Software.
  2. Paste this address into Work with: https://zacesshq.github.io/themes/eclipse/
  3. Tick Zacess Themes, finish the wizard and choose Trust Selected when Eclipse asks about unsigned content.
  4. Restart Eclipse, then pick a Zacess theme under Preferences, General, Appearance.

More

Eight themes, each with every text and syntax colour at 7:1 contrast or more. The same themes are available for VS Code, JetBrains IDEs, Neovim, Zed, Xcode and more.
